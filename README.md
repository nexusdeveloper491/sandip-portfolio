# Sandip Kundu — Full-Stack & Web Developer Portfolio

A modern, high-performance personal portfolio website built with pure vanilla web technologies. Designed with monumental typography, dark industrial aesthetics, responsive layout architecture, and interactive case study exploration.

🔗 **Live Website**: [https://sandipkundu.vercel.app/](https://sandipkundu.vercel.app/)

---

## ⚡ Highlights & Key Features

- **Monumental Industrial Aesthetic**: Bespoke dark UI featuring clean typography (`Anton`, `Outfit`, `JetBrains Mono`), glassmorphic panels, and subtle micro-animations.
- **Dynamic Case Studies & Gallery**: Interactive full-page modal showcase with live preview links, architecture details, and project screenshots.
- **Interactive Skills Filter**: Multi-category filterable skill matrix covering Frontend, Backend, Database, Cloud/DevOps, and CMS.
- **Interactive Experience Timeline**: Structured work experience overview with verified role metrics and technology badges.
- **Fully Responsive Architecture**: Custom-tailored layouts optimized across mobile devices (<=480px, <=640px), tablets (<=1080px), and ultra-wide screens.
- **Pure Vanilla Stack**: Zero bloated UI frameworks — engineered with native HTML5, modern CSS3 (Custom Properties & Flex/Grid), and vanilla JavaScript (ES6+).
- **SEO & Accessibility**: Clean semantic HTML5 structure, Open Graph tags, responsive meta tags, and ARIA labels.
- **Quick Communication Hub**: Direct contact dossier with WhatsApp, phone, email, and one-click copy buttons.

## 🚀 Getting Started Locally

This portfolio requires no build tools or package managers.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nexusdeveloper491/sandip-portfolio.git
   cd sandip-portfolio
   ```

2. **Open in browser:**
   - Double-click `index.html` directly, or
   - Serve using VS Code's **Live Server** extension, or
   - Use Python's built-in server:
     ```bash
     python -m http.server 3000
     ```
     Then open `http://localhost:3000`.
